# Các patch kiểm tra UI01-B

Ba patch trong thư mục này ghi lại đề xuất ban đầu cho B3, UI01-C1 và D2.
Sau đó người dùng đã cho phép trực tiếp sửa các feature và retest; các patch đã
được áp dụng vào working tree. Không áp dụng lại lên code đã sửa.

Giữ patch để reviewer đối chiếu ownership/phạm vi. Kết quả kiểm tra hiện tại
xem [handoff UI01-B](../../../handoffs/UI01-B.md); merge không được thực hiện tự động.
