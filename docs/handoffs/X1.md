## Feature freeze và giới hạn

Feature freeze được mở sau khi flow thật và regression suite xanh. X2 có thể dùng
commit này làm baseline để ghép browser E2E vào CI; D3/C3 có thể lấy X1 làm mốc ổn
định theo dependency. A2 vẫn `IN_PROGRESS` vì phần CI browser chỉ hoàn tất sau X2.

Natural JWT expiry không chờ đủ thời lượng trong lượt này; API bearer hết hạn/không hợp
lệ đã nhận 401. Native browser zoom, screen reader, Safari/Firefox/touch và full
accessibility matrix giữ giới hạn đã ghi ở handoff UI01-B.
