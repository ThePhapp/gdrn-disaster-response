# X2 — Browser regression và ghép CI

**Nhánh:** `feat/x2-a2-browser-ci`<br>
**Nền:** `main` tại `761e6f5`<br>
**Trạng thái:** DONE trên nhánh, chờ review/merge.

X2 dùng Playwright hiện có, không tạo framework thứ hai. Các flow chạy qua browser
production frontend, Nginx `/api`, backend thật và PostGIS thật. `APIRequestContext`
chỉ tạo dữ liệu fixture và cleanup trong database demo test; không intercept API nghiệp vụ.
Map failure chỉ abort request style/tile trong test chuyên biệt để kiểm tra fallback thủ công.

## Phạm vi regression

- Citizen/authority login, sai mật khẩu, reload giữ session, logout và role guard.
- S01 layout/keyboard ở 360/768/1280; English mặc định và chuyển VI.
- S05 disaster create/edit/resolve, validation/map fallback và text resize 200%.
- C2 reporting verify/reject/withdrawal/ownership/permission/radius filter.
- D2 rescue assignment, conflict `409 TEAM_BUSY`, mission progress và citizen progress.
- S06 detail, reduced motion, keyboard focus, responsive reflow và map read-only.
- Backend `401` thật sau khi session token hết hạn được trả về login.

Các test tiếng Việt dùng `frontend/e2e/fixtures.ts` để set preference `gdrn.language=vi`
trước khi mở trang. `language.spec.ts` dùng context sạch để giữ kiểm tra English mặc định.
`scripts/browser-e2e.ps1` nạp `.env`, nhận `E2E_BASE_URL`/`E2E_API_URL` theo port host;
có thể nhận `-EnvironmentFile` để chạy database test cô lập.

## CI handoff cho A2

`.github/workflows/ci.yml` thêm job `browser-e2e` độc lập trên `ubuntu-latest`:

1. Pin Node từ `frontend/.nvmrc`, `npm ci`, cài Chromium bằng
   `npx playwright install --with-deps chromium`.
2. Sinh `POSTGRES_PASSWORD`, JWT key và demo password tạm; mask trong log và ghi vào
   `.env` ignored của job.
3. Validate Compose, `up --build --wait`, smoke gateway rồi chạy
   `scripts/browser-e2e.ps1` với frontend `5174` và API `18080`.
4. Upload test results/HTML report/trace/screenshot khi lỗi; cleanup bằng `down` và xóa
   `.env`, không xóa volume bằng `down -v`.

Remote GitHub Actions chưa được chạy vì nhánh chưa push. Sau khi push/ mở PR, check cần
được xác nhận là job `browser-e2e`; local evidence đã bao phủ đúng command, ports,
temporary secrets và cleanup của job.
