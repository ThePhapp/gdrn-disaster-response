## Phạm vi đã hoàn tất

A1 đã rà soát E01–E15 sau khi B2 và D1 có mặt. Security policy vẫn nằm ở
`com.gdrn.shared.infrastructure.configuration.SecurityConfiguration`; module
application tiếp tục kiểm tra ownership và điều kiện nghiệp vụ từ principal đã xác
thực. Không thêm endpoint, authentication giả, user seed, registration, refresh hay
logout API.

| Endpoint | Role ở route policy | Kiểm tra ownership/điều kiện |
| --- | --- | --- |
| E01 `POST /api/auth/login` | PUBLIC | Identity xác thực credential và trả lỗi đồng nhất |
| E02 `GET /api/auth/me` | CITIZEN, AUTHORITY | Identity đọc user từ verified principal |
| E03/E04 `GET /api/disasters[/{id}]` | CITIZEN, AUTHORITY | Disaster application xử lý id và dữ liệu |
| E05 `POST /api/disasters` | AUTHORITY | Disaster application quyết định input/lifecycle |
| E06 `PATCH /api/disasters/{id}` | AUTHORITY | Disaster application kiểm tra version/transition |
| E07 `POST /api/reports` | CITIZEN | Reporting lấy owner từ principal, không từ body |
| E08 `GET /api/reports` | CITIZEN, AUTHORITY | Reporting giới hạn citizen theo owner |
| E09 `GET /api/reports/{id}` | CITIZEN, AUTHORITY | Reporting trả quyền owner hoặc authority |
| E10 `PATCH /api/reports/{id}/verification` | AUTHORITY | Reporting quyết định transition |
| E11 `DELETE /api/reports/{id}` | CITIZEN | Reporting kiểm tra owner và PENDING |
| E12 `GET /api/rescue-teams` | AUTHORITY | Rescue read policy |
| E13 `POST /api/rescue-missions` | AUTHORITY | Rescue kiểm tra report/disaster/team và race |
| E14 `GET /api/rescue-missions` | CITIZEN, AUTHORITY | Rescue giới hạn citizen theo report ownership |
| E15 `PATCH /api/rescue-missions/{id}/status` | AUTHORITY | Rescue kiểm tra transition |

Route matcher Disaster được thu hẹp từ `/**` về đúng collection và một path
parameter. Vì vậy các path lồng chưa đăng ký như `/api/disasters/unknown/nested`
không được hưởng quyền của E03/E04 và tiếp tục bị default-deny. OpenAPI runtime
`disaster.json` và `rescue.json` cũng đã khai báo `bearerAuth` trên toàn bộ E03–E06
và E12–E15; E01 giữ security empty, E02 và E07–E11 đã có Bearer metadata.

Shared SPA behavior đã được đối chiếu với UI01-A: nav chỉ render route đúng role,
`RoleGuard` bảo vệ route, token chỉ ở memory, 401 clear session, 403 giữ phiên,
409 không tự retry, logout/expiry dọn session và generation ngăn response trễ ghi
vào user mới. Regression test khóa đủ route export hiện có và landing path của hai
role; test không tạo mock API runtime.
