Không trở ngại cho tài liệu P00. Có giới hạn bằng chứng Java21 nêu trên; đầy đủ xác minh đã
chạy thật, không bỏ qua tích hợp. Điều kiện kiểm tra runtime/frontend/permission/race của tính năng
chưa thực thi vì thuộc các công việc sau.

Tool kiểm tra dữ liệu được cài riêng trong `.tools/` được Git bỏ qua, không thêm phụ thuộc dự án.
Lần thử Python MinGW 3.11 không cài được phụ thuộc cài trực tiếp (maturin unsupported
platform); chuyển sang CPython Windows 3.14 sẵn có và kiểm tra tính hợp lệ thành công. Tái lập
trên Windows từ gốc kho mã:

```powershell
py -3.14 -m venv .tools/p00-native
.\.tools\p00-native\Scripts\python.exe -m pip install PyYAML==6.0.3 openapi-spec-validator==0.7.2
.\.tools\p00-native\Scripts\python.exe docs/api/validate_phase1_contract.py
.\mvnw.cmd clean verify
git diff --check
```

Máy khác có thể dùng CPython tương thích/venv tương đương; validator chỉ đọc tài liệu,
không gọi API hay chạm DB. Script nằm trong kho mã để rà soát không phụ thuộc generator
tạm. Đầy đủ ứng dụng phía máy chủ kiểm thử cần Docker; không thay bằng unit-only khi Docker thiếu.
Để rà soát P00, mở YAML/Markdown/ADR, đối chiếu decision table; chưa có trình diễn UI nghiệp vụ.
