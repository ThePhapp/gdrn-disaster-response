## Runtime đã triển khai

- `frontend/Dockerfile` dùng multi-stage `node:22.14.0-alpine` để chạy `npm ci` và
  `npm run build`, sau đó phục vụ artifact bằng `nginx:1.27-alpine`.
- `frontend/nginx.conf` phục vụ `/login` và deep route bằng SPA history fallback;
  `/api` proxy tới `backend:8080` trong mạng Compose. Browser chỉ dùng URL tương đối
  `/api`, không thấy hostname container.
- Compose có `database`, `backend`, `frontend`; named volume `database-data` vẫn được
  giữ. Frontend chờ backend healthy, backend chờ database healthy. `FRONTEND_PORT`
  mặc định `5173` và có thể đổi riêng trong `.env`; `APP_PORT`/`DB_PORT` giữ nguyên.
- Public `VITE_*` map config chỉ đi qua build args nếu người dùng cấu hình; JWT,
  database password và DEMO credentials chỉ ở backend environment, không copy `.env`
  vào frontend build context.
- `scripts/local.ps1` vẫn chạy Vite host cho dev và đọc `FRONTEND_PORT`; `scripts/dev.ps1`
  chạy full Compose và smoke health/API/frontend.

## CI hiện có

`.github/workflows/ci.yml` giữ các check backend `bash ./mvnw clean verify` với Docker/Testcontainers,
frontend `npm ci`/typecheck/test/build, Compose config validation và bổ sung Compose
image build cho backend/frontend. Job smoke khởi động stack thật và dọn container sau
job. CI chưa chạy browser E2E vì X2 chưa cung cấp suite được chốt; không đánh dấu A2
DONE trước dependency đó.

Review follow-up giữ Maven Wrapper làm toolchain duy nhất trong CI. Lệnh
`dev.ps1 smoke -BaseUrl ...` chỉ kiểm tra backend chạy trên host như runbook mô tả;
smoke không truyền `BaseUrl` vẫn kiểm tra đầy đủ backend, frontend SPA và Nginx
`/api` proxy của Compose.

## Cách chạy sau clone

```powershell
.\scripts\dev.ps1 init
.\scripts\dev.ps1 up
.\scripts\dev.ps1 smoke
```

Mặc định mở `http://127.0.0.1:5173/login`, backend health ở
`http://127.0.0.1:8080/actuator/health`, Swagger ở
`http://127.0.0.1:8080/swagger-ui/index.html`. Cách phát triển nhanh bằng Vite host
vẫn dùng `scripts/local.ps1 -Action setup/start`; không dùng `docker compose down -v`
để làm mất database volume. Hướng dẫn đầy đủ đã cập nhật tại README,
`docs/HUONG_DAN_CAI_DAT_VA_CHAY.md` và `docs/P01_LOCAL.md`.
